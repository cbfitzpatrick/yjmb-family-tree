YJMB Family Tree v19.1.3 — Leadership Taxonomy Admin

Overlay this patch on v19.1.2.

Changes:
- Adds Admin Mode > Leadership Taxonomy.
- Scrubs every Position and Year value into unique position titles.
- Shows occurrence counts, built-in classification, current override, and sample people.
- Lets administrators map titles to Drum Major, Section Leader, Guard Captain,
  RAT Parent, MCM, Libraries, Uniforms, Band Club, Informal Leadership,
  Other Leadership, or No icon / not leadership.
- Automatic/default removes an Admin override.
- Stores overrides in a very-hidden Leadership Taxonomy worksheet in the
  protected master workbook; no public plaintext taxonomy file is required.
- Applies one classification to every matching title on subsequent rebuilds.
- Extends encrypted changelog/revert support to taxonomy cells.
- Normal cards consume the generator's authoritative icon flags so Admin
  taxonomy overrides cannot diverge from browser-side parsing.
- Includes all v19.1.2 leadership parser and icon-folder export fixes.

No Markdown, plaintext member data, encrypted tree payload, protected workbook,
or secret files are included in this package.
