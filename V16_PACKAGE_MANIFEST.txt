YJMB v16 cumulative drop-in upgrade
===================================

This overlay includes the v15 upgrade plus v16 revisions. It is intended to be
copied over an existing configured pre-v15 project.

INTENTIONALLY NOT INCLUDED
--------------------------
- YJMB Trees.xlsx
- access_secrets.json
- .dev.vars / .env secret files
- secure/ generated encrypted/private payloads
- Git metadata
- Cloudflare/GitHub secret values

NEW/REVISED IN V16
------------------
- section normalization with subsection/detail retention
- smartphone-only responsive tree/questionnaire/gate refinements
- compact bug-report icon
- compact spacing for people with neither a VET nor a RAT
- Guard Captain formal leadership + flag icon
- extractMarriedNamesFromNotes.py
- full Current/Married Name display in person details
- fail-closed Git-index handling in verify_public_repo.py

See README_DROP_IN_UPGRADE_V16.md for the exact installation/deployment flow.
